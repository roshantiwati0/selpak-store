1. Project ek nazar me

Kya bana rahe hain: Selpak ke tissue aur hygiene products (toilet paper, kitchen towel, facial tissue, hanky, wet wipes, napkin) bechne ke liye ek B2C online store. Customer product dekhega, cart me daalega, address bharega aur online (Razorpay) ya cash on delivery se order karega.

CheezFaisla
CustomerSirf ghar ke customer (B2C). Business / wholesale shamil nahi.
Products40 products, 6 categories (Selpak Catalogue 2026). Price = MRP.
PaymentRazorpay (UPI, card, net banking) + Cash on delivery
Hamari teamSirf frontend. Backend (database, API, payment verify) dusri team banayegi.
SellerHariom Marketing, Mumbai
Abhi ki haalat: frontend ka pehla poora version ban chuka hai aur demo mode me bina backend ke chalta hai: browse, search, filter, cart, checkout, order, login, orders, contact. Aage ka kaam: backend se jodna, asli payment, sir ke jawab ke hisaab se badlav, testing aur launch.

3. Project kaise chalayein

Ek baar ka setup: Node.js (version 20.9 ya naya), Git aur VS Code install karo.

# 1. Code lao
git clone https://github.com/roshantiwati0/selpak-store.git
cd selpak-store/web

# 2. Packages install karo (pehli baar 2-3 minute)
npm install

# 3. Site chalao
npm run dev            # browser me http://localhost:3000 kholo
CommandKya karta hai
npm run devDevelopment server. File save karte hi browser me badlav dikhta hai.
npm run lintCode ki galtiyan check karta hai. Har commit se pehle chalao.
npm run buildProduction build. Agar yeh fail ho to code merge nahi hoga.
npm run startBuild ki hui site chalata hai (launch jaisa).
Demo mode: backend ke bina login ka OTP hamesha 123456 hai, orders aapke browser me save hote hain, aur "Pay online" ek test screen kholta hai jisme koi asli paisa nahi katta. Settings web/.env.example me samjhayi gayi hain.

6. Team: kaun kya sambhalega

Kaam 4 hisso me banta hai. Har hissa ek "owner" ka hai: wahi us hisse ki files badalta hai, bugs theek karta hai aur backend se jodta hai. Dusre log us hisse me badlav Pull Request se bhejte hain aur owner review karta hai.

A. Lead + Foundation

Sabse anubhavi member
  • Files: app/layout.tsx, globals.css, Header, Footer, BottomNav, lib/config.ts, store/createStore.ts, sitemap.ts, robots.ts
  • GitHub repo, branch rules, Pull Request review aur merge
  • Design system ko sahi rakhna (naye colour / size par rok)
  • Backend team se baat, API_CONTRACT.md ka maalik
  • Deployment (hosting, domain, env settings), SEO

B. Catalogue

Products dikhana aur dhoondhna
  • Files: app/page.tsx (home), app/shop/, app/product/, ShopView, ProductCard, BuyBox, lib/catalog.ts, data/catalog.ts, public/products/
  • Product data aur images sahi rakhna; sir se behtar photos / description lena
  • Search, filter, sort; home ke banners
  • Backend aane par lib/catalog.ts ko API se jodna

C. Cart + Checkout + Payment

Sabse zimmedari wala hissa (paisa)
  • Files: app/cart/, app/checkout/, app/order/, CartView, CheckoutView, DemoPayment, OrderView, store/cart.ts, store/address.ts, lib/razorpay.ts
  • Razorpay test mode me asli payment jodna aur test karna
  • Delivery charge, pincode check ke rules lagana
  • Payment fail / cancel / dobara try ke saare case test karna

D. Account + Support + QA

Login, orders, madad, testing
  • Files: app/login/, app/account/, app/contact/, app/policies/, LoginView, OrdersView, ProfileView, AccountNav, ContactForm, store/auth.ts, lib/policies.ts
  • Asli OTP login jodna; orders list, tracking
  • Policy pages ka asli text sir se lekar daalna
  • QA: har hafte poori site mobile aur desktop par test karna, bug list banana
Agar team me 3 log hain: D ka kaam baant do: Login / Account / Orders → C ko, Contact / Policies → B ko, aur QA → A (Lead) ko.
Saanjhi files (lib/types.ts, lib/api/, globals.css): inhe sab chhute hain, isliye sabse zyada takraav yahin hota hai. Inme badlav chhote rakho, alag PR me bhejo, aur group me pehle bata do.

Rules

  • main par seedha push nahi. Har badlav Pull Request se, aur kam se kam ek aur member ka review.
  • Ek PR = ek kaam. Chhota PR jaldi review hota hai. 300 line se bada ho to tod do.
  • Roz subah git pull aur apni branch me git merge main, taaki takraav chhote rahein.
  • Commit message: "kahan: kya kiya", jaise Cart: quantity 20 se upar nahi jaati.
  • PR me likho: kya badla, kaise test kiya, aur UI badla ho to mobile + desktop ka screenshot.
  • .env.local, passwords, API keys kabhi commit nahi.

Roz ki 10 minute ki meeting

Har member 3 baatein bataye: kal kya kiya, aaj kya karunga, kahan atka hu. Kaam ki list ke liye GitHub Issues ya Projects board use karo (To do → In progress → Review → Done), aur har issue par ek owner ho.

9. Backend team ke saath kaam

Poora detail docs/API_CONTRACT.md me hai. Yeh file backend team ko pehle hafte me de do aur saath baith kar finalize karo.

#EndpointKaamOwner
1POST /auth/otpMobile par OTP bhejnaD
2POST /auth/verifyOTP check, login token denaD
3GET /delivery/pincode/:pinIs pincode par delivery hai ya nahiC
4POST /ordersOrder banana (price backend nikalega)C
5POST /orders/:id/razorpayRazorpay order bananaC
6POST /orders/:id/verify-paymentPayment signature check karnaC
7GET /ordersLogin wale customer ke ordersD
8GET /orders/:idEk order ka detailC
9POST /contactContact form ka messageD
10-12GET /categories, /products, /products/:idProducts (abhi frontend ki file se)B

Backend se jodne ka tarika

  1. web/.env.local me NEXT_PUBLIC_API_URL=... daalo. Bas itne se app demo ki jagah asli backend (lib/api/http.ts) use karne lagta hai.
  2. Ek-ek endpoint jodo aur test karo: pehle login, phir order (COD), phir online payment.
  3. Jo response contract se alag aaye, pehle backend team se baat karo, phir API_CONTRACT.md aur http.ts dono badlo.
Suraksha ke 3 pakke rule: (1) Razorpay ki secret key kabhi frontend ya GitHub me nahi. (2) Order ka total hamesha backend nikale; frontend ke bheje price par bharosa nahi. (3) Payment "paid" tabhi mane jab backend signature verify kar le.
